# World Awakened Phase 8 Test Pack

Standalone invasion pressure-event validation datapack for Phase 8.

This pack is self-contained and can be installed without `worldawakened_example_pack`.

## Install

Copy `worldawakened_phase8_test` into a world's `datapacks/` folder, then run:

```text
/reload
/wa reload validate
```

## Contents

- invasion profiles (`invasion_profiles/`)
- invasion-gated mutation pools (`mutation_pools/`)
- spawn-event mutator pressure rules (`rules/mutators/`)
- invasion reward loot profiles (`loot_profiles/`)
- supporting mutator definitions for pool references (`mob_mutators/`)
