# Superseded In-Game/Admin UI Proposal

- Document status: Superseded
- Last updated: 2026-10-17

The native in-game configuration interface is no longer a deferred post-v1 idea. Its first focused, server-authoritative settings screen is implemented through `/wa config`.

See [SIMPLIFICATION_AND_DEFAULT_GAMEPLAY.md](SIMPLIFICATION_AND_DEFAULT_GAMEPLAY.md) for the current scope and delivery sequence. Later editor milestones cover registry browsing and authored-definition editing; advanced or obscure framework features may remain datapack-only rather than being forced into a confusing GUI.
